# Clientes

Cada cliente tem a sua propria pasta aqui dentro.

## Como criar a pasta de um novo cliente

1. Copie a pasta `_modelo` e renomeie para o nome do cliente em minusculo e sem espacos (ex: `padaria-sol`).
2. Preencha a ficha em `README.md` da pasta do cliente.
3. Coloque os arquivos do site dentro da pasta `site/`.
4. Adicione o cliente na tabela abaixo.
