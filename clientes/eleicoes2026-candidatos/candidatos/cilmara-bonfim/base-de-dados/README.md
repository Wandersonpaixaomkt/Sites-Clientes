## Uso desta pasta

- **Conteúdo validado:** frases, marcos e números daqui podem aparecer em materiais oficiais.
- **Conteúdo em revisão:** qualquer item ainda em checagem (datas, nomes, números de votação) deve ser validado com a coordenação antes de publicação.
- **Conteúdo sigiloso:** documentos com dados pessoais, jurídicos ou estratégicos têm circulação restrita à equipe de coordenação.
