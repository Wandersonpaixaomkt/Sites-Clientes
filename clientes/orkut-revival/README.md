# Orkut Revival

Reconstrução nostálgica e responsiva da experiência final do Orkut, inspirada
na interface utilizada até 2014.

## Recursos

- mural de atualizações com reações;
- perfil, scraps e depoimentos;
- comunidades e tópicos de fórum;
- notificações e chat simulado;
- temas clássico, azul e escuro;
- adaptação para desktop, tablet e celular.

## Executar localmente

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```

Projeto independente criado para demonstração histórica e educacional.
